
# 🧮 Calculadora em C

Uma calculadora desenvolvida na linguagem C como exercício prático de lógica de programação e dos fundamentos da linguagem.

## 🎯 Objetivo

Explorar os conceitos básicos de programação em C por meio da implementação de operações matemáticas e da interação com o usuário pelo terminal.

## ✨ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão

*As operações acima devem corresponder às funcionalidades implementadas no código.*

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Compilador C, como GCC

## 🚀 Como executar

1. Instale um compilador C, como o GCC.
2. Clone este repositório:

   ```bash
   git clone https://github.com/RilouDev/calculadora-em-C.git
   ```

3. Entre na pasta do projeto:

   ```bash
   cd calculadora-em-C
   ```

4. Compile o programa, substituindo `calculadora.c` pelo nome real do arquivo:

   ```bash
   gcc calculadora.c -o calculadora
   ```

5. Execute o programa:

   **Windows:**
   ```bash
   calculadora.exe
   ```

   **Linux:**
   ```bash
   ./calculadora
   ```

## 📚 Aprendizados

Este projeto permite praticar conceitos como:

- Declaração de variáveis e tipos de dados.
- Operadores aritméticos.
- Entrada e saída de dados.
- Estruturas condicionais.
- Compilação e execução de programas em C.
